PACOTES ESSENCIAIS INSTALADOS PELO setup.sh
============================================

O instalador executa `pkg update -y` e `pkg upgrade -y` uma vez durante a preparação.

Pacotes essenciais processados individualmente:

python
git
zip
unzip
openjdk-17
gradle
clang
make
cmake
pkg-config
findutils
coreutils
sed
grep
tar

Comportamento:
- O setup.sh verifica se cada pacote já está instalado com dpkg.
- Pacotes já instalados são pulados e não são baixados novamente.
- Pacotes novos são instalados um por vez, em sequência visível.
- O inventário persistente fica em `~/.config/gemini-termux-agent/installed-packages.txt`.
- Se um pacote essencial falhar após três tentativas, o instalador para e informa o erro.
- Dependências extras específicas de um projeto podem variar, mas o agente não repete a preparação geral do Termux a cada projeto.
- `termux-setup-storage` não é um pacote: cria os atalhos de acesso ao armazenamento do Android.
